# GitHub launch checklist

1. Create a public repository named `devoniq-aris` or `aris-open-core`.
2. Upload the contents of this package at repository root.
3. Keep `.env.local` and all API keys out of git.
4. Use `main` as the default branch.
5. Enable GitHub Issues and Discussions.
6. Let the included CI workflow run before announcing the repo.
7. Add a 20-60 second demo clip to the README after the public release is stable.
8. Tag the first public version `v0.2.0`.
9. Pin the repo on the founder profile and Devoniq organization profile.
10. Do not claim real-aircraft validation until physical testing exists.

Recommended repository description:

> Open-source mission-intelligence and simulation core for hardware-agnostic drone autonomy.

Recommended topics:

`drones`, `robotics`, `autonomy`, `simulation`, `pybullet`, `ai`, `computer-vision`, `path-planning`, `uav`
