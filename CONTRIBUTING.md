# Contributing

Thanks for helping improve ARIS Open Core.

1. Open an issue for non-trivial changes.
2. Keep changes small and testable.
3. Add or update tests for behavior changes.
4. Do not add credentials, private aircraft endpoints, or customer data.
5. Run `python -m pytest` before opening a pull request.

Pull requests that add weaponization, targeting, or autonomous pursuit of people
will not be accepted.
